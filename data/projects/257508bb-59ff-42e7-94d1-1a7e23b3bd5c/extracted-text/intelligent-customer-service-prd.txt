# 智能客服系统

## 文档信息

|  |  |
| --- | --- |

| **项目负责人** | 林浩天 |

## 1. 项目概述

基于NLP技术的智能客服系统，实现自动化客户咨询处理，降低人工客服成本。

## 2. 项目时间

|  |  |
| --- | --- |
| **开始时间** | 2023年6月 |
| **结束时间** | 2024年5月 |

## 3. 项目成果

* 准确率达95%以上
* 日均处理10万+咨询
* 降低客服成本60%
